## 3. Options

- (a) Leave out young holdings + renormalise, keeping listwise: **rejected alone** (the day a name re-enters, the window collapses to its N returns; does nothing for a 2-month-old holding, which truncates the book today).
- (b) Pairwise: **rejected** (historical VaR / CVaR / drawdown need one return series; a pairwise covariance can fail PSD; a young name's beta is unmeasurable anyway).
- (c) Proxy (sector fund / SPY): **rejected** (invents IPO-period returns; IPOs are more volatile than their fund, so it understates exactly the name at issue; memory `blank_beats_forced_guess`).
- **(d) Recommended: available-weight series + young-holding floor + a cap on the unmeasured share**, one rule in a new pure module:
  1. **Counted holding:** ≥ `BETA_MIN_RETURNS` (= 20, the existing literals' value) real daily returns in the frame the metric uses, so "young" = "its own beta can't be measured yet" (the same day `risk.beta_vs_market` turns non-None given SPY, `stress_test.py:317` stops substituting the book beta, and the risk-off ranking `exit_advisor.py:657` can see the name).
  2. **Book return on day t** = Σ w_i·r_i,t / Σ w_i over counted holdings with a return on t; interior gaps forward-filled as today; days before a holding's first close are not.
  3. **A day is kept** only if that day's unmeasured weight (young + no prices + counted-but-not-yet-trading) ≤ `PORTFOLIO_RISK_UNMEASURED_MAX_PCT`. No qualifying day, or fewer than `PORTFOLIO_RISK_MIN_DAYS` (= 10, today's :535 floor) → **None** (the existing offline contract).
  - With ANT at a few percent: the window stays ≈ 124 returns, every metric on the other ≈ 96%, disclosed. Above the cap: None → fragility / advisor None, C2a holds β > `TICKER_BETA_CRITICAL` as `beta_unknown` (the right fail-closed direction for G-06).
  - **Understatement:** beta is off by ≈ s·(β_young − β_rest): at s = 10%, a β 2.5 IPO in a 1.3 book → 0.12 too low (enough to hide a 1.29 → 1.41 crossing of `PORTFOLIO_BETA_CEILING`); at s = 5% ≈ 0.06. Hence the cap is the owner's call (Q1).
  - Disclosure: "Portfolio risk measured without ANT (3.6% of the book: 9 days of prices, 20 needed); its weight is spread over the other holdings."
  - **No-op for normal books:** when every counted holding spans the whole window, (d) equals today's series exactly; only young / short windows change.

## 5. Edge cases

Clock-free (counts rows in the frame it is given; no `today`), so the time-context matrix reduces to frame shapes: weekend / 11-26 holiday (last row Fri / Wed), pre-open (no row for today), intraday (a partial bar counts as a return, as in `beta_vs_market`; premarket vs 09:45 can differ by one count, consistently with the name's own beta), after hours (final bar), DST week and mixed tz-aware ET / naive indexes (normalised). Only-young book → None, every name listed. Several young names → weights add against the cap. Halted name → counted, gaps forward-filled, `n_returns` counts real closes only. Split → out of scope (provider adjustment, as today). 19 → 20 → 21 transition → window length constant, ANT moves from left out to counted at exactly 20 returns. SPY missing → beta None, other metrics and coverage present. Unpriced row with NaN weight → listed "no_prices", left out of the share (size unknown); C2a's `fit_unknown` already covers it on the cron path.
