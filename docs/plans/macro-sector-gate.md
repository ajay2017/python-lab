The ETF lane is already fail-closed (`etf_candidates.etf_macro_block_reason`, `etf_candidates.py:190-215`).

**MacroAff.** Not ordering. On 11-03 NFP was 3 days out (= `MACRO_IMMINENT_DAYS`), so the card was the Monitoring item from `_review_list` block 5 (`daily_briefing.py:3655-3853`).
