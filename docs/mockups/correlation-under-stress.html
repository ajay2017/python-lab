⚠️ Read this directionally, not as a hidden link. A sharp ~25-day crash mechanically pushes correlations up because everything drops together — this shows how your book actually moved during that specific crash, not that these names are secretly connected.
Honesty rules encoded here:
• Window length always shown — "25 trading days" — so a short window's mechanical correlation-inflation isn't mistaken for a real structural finding.
• Coverage caption — which held names are excluded and why (didn't trade through the window), never silently dropped.
• Calm-advisor framing — "your book moved as one" / "read directionally," never "these names are secretly linked."
• Lazy-load, not automatic — a button click, not a fetch-on-every-rerun (same pattern as the existing Stress Testing tab).
• Reuses existing thresholds — the same 0.65/0.80 tiers as the calm clusters above, no new constant.
• Custom range never silently falls back — an invalid/too-short range disables the Load button with an explicit reason caption, unlike a similar picker already shipped elsewhere in the app that this deliberately does NOT repeat.
• Preset windows can never regress — the 10-trading-day floor is measured on actual aligned trading rows, and all 3 presets comfortably clear it; only custom ranges can hit the floor.
• Cross-references 🔥 Stress Testing — shown only for the 3 presets (not custom ranges, which have no P&L lookup there) — pure discoverability, no coupling.
