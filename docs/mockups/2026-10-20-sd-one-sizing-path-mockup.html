What changes, in one line each.
• Every add size now counts what you already hold: the whole position must stay under 15% of the book and under 25% of net capital (strictly under, so the 📒 Trade Journal's post-trade check never flags a size the app suggested).
• Grow Today: partial room → smaller add plus a "Capped by what you already hold" line; no room → the name moves to a new "Position Already at the Cap" block (gate G-31), never silently dropped.
• 📈 Analysis on a held name shows Grow Today's add call (add / paused / no call / unavailable) and its size — it never sizes an add itself, so every add pause in Grow Today (recently added, deterioration watch, sector cap, trim call, correlation, entry check, room) now holds on Analysis too.
• Not-held names on Analysis are unchanged (the shared entry check still decides).
• Unchanged here: the Grow Today risk footer (chunk C3), Watchlist / Rebalancer / Diversification / Econ / Catalyst counts (chunks C4–C6).
