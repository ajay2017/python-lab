Honesty rules encoded in the design
• Alpha, not raw % — headline is vs-S&P, per feedback_analytics_integrity.
• new_pick scope — excludes the awareness-only buy_candidate feed (skipping those is correct, not a miss).
• Maturity-gated — only calls older than REC_SCORE_MIN_DAYS (=5) count.
• Coverage caption — states plainly that the BUY log is visit-dependent, so it measures surfaced calls, not all theoretical calls.
• Sample floor — "Building history" empty state below a minimum call count; "Too early" softening just above it.
• No recompute — reads summary_stats()/by_verdict(); links through instead of duplicating.
