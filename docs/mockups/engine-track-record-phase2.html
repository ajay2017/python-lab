Honesty rules encoded here (carried from F-229's review rounds):
• Never dress absent as negative — building/offline both render neutral grey, never a computed number.
• Never dress flat/negative as failure or hide it — "RAN EARLY" is calm and honest, not "LAGGING"/red — a protective call that fires early isn't necessarily wrong, it's early; framed as such rather than punitively.
• Distinct badge vocabulary — VALIDATED / RAN EARLY (Defense) vs WORKING / LAGGING (Offense) so the two facets are never confused for the same claim.
• No link-through on Defense — no detail page exists for this facet yet; only Offense links to 📜 Recommendations History.
• Dedup invariant (not visible in the UI, but load-bearing) — each flagged ticker counts ONCE (earliest mature signal), never once per cron-day it stayed flagged.
