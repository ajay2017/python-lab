System Proprioception — Phase 1 mockup

Owner-only 🩺 System Trust diagnostic page + a top-of-Home degraded-only chip. Phase 1 informs only — it changes no gate, no recommendation. Pull-based / render-time (no dependence on its own cron). Reuses the 🔬 Model Lab owner-only-hidden nav pattern (app.py:2175). Content below is illustrative.

Frame A · Top-of-Home chip — DEGRADED state (only renders when something is wrong)
⚠ 2 pipeline checks degraded today — 1 expected data table is missing and marks are running on a backup source. Open System Trust →

This is the only thing proprioception adds to a decision surface in Phase 1: one line, at the top of Home, only when a check is amber/red. It informs and links — it does not suppress anything.
