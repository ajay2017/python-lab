A small pure helper turns each "•" or "-" line into a markdown list item at display time. It is applied to the saved text on screen, so every past debrief and monthly review is fixed too, with no regeneration. Prose sections (What happened, One thing to watch) stay paragraphs. The emailed text is unchanged.
The same helper also escapes $ in the monthly sections, which today go to st.markdown unescaped (two $ in one section would render as LaTeX). The weekly sections already escape it.
